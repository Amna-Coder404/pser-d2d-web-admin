# PSER D2D Admin Dashboard

A simple and modern dashboard for managing employees and their survey information.

## ✨ What It Does

* 🔐 Admin login and logout
* 👥 Add and manage employees
* 🟢 Activate or deactivate employees
* 🖼️ View employee profile pictures and details
* 📋 View submitted surveys
* 🔎 Filter surveys by employee
* 🌙 Clean dark design
* 📱 Works on desktop and mobile

## 🛠️ Built With

* React
* Vite
* Supabase
* Ant Design
* Lucide React
* Motion
* CSS

## 🚀 Run the Project

```bash
npm install
npm run dev
```

Create a `.env` file and add your Supabase project details:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_key
```
